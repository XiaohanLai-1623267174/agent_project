为什么要放在 public/：Vite 对 public/ 下的 HTML 不做转换 ⇒ 不会注入 HMR 客户端 ⇒ 无头 Chrome 截图时不会因为常驻 WebSocket 卡住（实测 --dump-dom 在本机直接返回 0 字节， 所以改用 --screenshot + 读图）。
运行方式：npm run dev 起 Vite，然后
chrome --headless=new --virtual-time-budget=15000 --window-size=1100,1700 --screenshot=out.png http://localhost:5173/_markdown_sanitize_device.html
